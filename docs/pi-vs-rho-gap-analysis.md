## 7. Prioritized Roadmap

### Phase 1: Core AI Parity (High Priority)
**Target: Match Pi's AI provider coverage and model catalog.**

1. ✅ Expand model catalog from ~30 to ~500+ models (from Pi's `models.generated.ts`)

6. ✅ Add prompt caching (cache control headers, Anthropic + OpenAI)
7. ✅ Add WebSocket transport for OpenAI Codex
8. ✅ Add lazy provider loading
